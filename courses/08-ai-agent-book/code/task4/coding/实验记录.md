# 第五章相关实验：反馈驱动的代码修复

本实验为自拟的最小相关实验，不是教材编号实验。当前对话中的 Coding Agent 实际读取、修改本地代码并执行测试，没有另建独立模型调用框架。

## 第一轮：折扣公式

需求：150 元减免 20% 应实付 120。初始公式 `sum(prices) * discount` 计算了减免金额。改为 `sum(prices) * (1 - discount)` 后，原有四项测试通过。原始记录为 before.txt、after.txt。

## 第二轮：范围校验

需求：discount 只能在闭区间 [0, 1]，越界及 NaN 抛 ValueError。字符串、None 等类型行为不在本次契约内。

1. Read：读取 cart.py 与原有四项测试，确认尚无范围校验。
2. Think：保留已有 0、1 边界测试，新增负值、超过 1、NaN 三项异常测试。
3. Execute/Observe：修改实现前运行七项测试，原四项通过、新三项均以 `ValueError not raised` 失败。见 range-before.txt。
4. Edit：新增 `if not (0 <= discount <= 1): raise ValueError(...)`。
5. Execute/Observe：原样重跑七项测试，全部通过，进程退出码 0。见 range-after.txt。

这提供了从已知缺陷到修复的实际反馈证据，只覆盖已列用例，不证明所有输入正确，也不表示所有第五章编号实验已完成。

## 亲自复跑

在本目录运行 `python -m unittest -v`，应看到七项通过。

对照已按用户要求实际执行：仅将校验条件改为 `discount < 0 or discount > 1`，七项中仅 NaN 测试失败，原因为 `ValueError not raised`，进程退出码 1，见 comparison-or.txt。随后恢复闭区间校验 `not (0 <= discount <= 1)`，七项全部通过，进程退出码 0，见 comparison-restored.txt。测试用例在对照期间保持不变，最终代码已恢复为闭区间校验。
