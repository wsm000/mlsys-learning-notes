# Task 2｜Memory 与 RAG 实验报告

执行日期：2026年10月15日。机器：vm-60。状态：主 RAG 实验与两项补充实验均已实际运行，组合偏好遵从检查失败，详见下方。

## 方法与环境

课程：https://github.com/bojieli/ai-agent-book/tree/main/chapter3
模型使用方式：https://huggingface.co/BAAI/bge-small-zh-v1.5

本实验为自编最小教学实验，不是教材完整实验3-4或3-6验收；7篇文档均为明确标注的虚构“星舟笔记”资料。结论仅适用于本次小样本。问题和预期答案在运行前写入 questions.json。

- Python 3.10.12，PyTorch 2.9.1+cu128，Embedding实际在CPU计算。
- 真实Embedding：BAAI/bge-small-zh-v1.5，512维；查询加模型要求的检索前缀，文档不加；CLS池化后L2归一化。
- 权重版本：7999e1d3359715c523056ef9478215996d62a620；权重与配置SHA-256见environment.json。
- 中文关键词基线：字符二元组与英文/错误码完整词元，手写BM25，k1=1.5、b=0.75。
- 稠密检索：全部归一化向量做精确点积排序，等价于余弦相似度；本实验不涉及ANN或向量数据库服务。
- 分块：60字与120字，重叠20字，保留原文偏移、来源ID、active/superseded状态。
- 每题取Top-2；比较关键词、向量、过滤失效版本后的向量检索。
- 生成：同一个AMD DeepSeek-V4-Flash，temperature=0；四组分别为无检索、关键词、向量、过滤后向量。每组将相同四题批量调用一次，全部使用120字分块的检索证据；不带上一组会话。所有组使用相同“只按证据回答”的提示。

主链路：文档 → 分块 → 真实Embedding → 精确相似度排序 → 选取片段 → 将片段和问题放入AMD请求 → 回答与引用。

## 实际结果

| 观察项 | 真实结果 | 解释 |
|---|---|---|
| 不提供检索证据 | 四题都回答资料不足 | 这是严格按证据回答的基线，不能由此推断所有无RAG模型都会拒答 |
| 120字分块，关键词检索 | 三道有答案的问题都回答正确；未知优惠拒答 | 本小样本无需向量也能命中，不能声称向量全面胜出 |
| 120字分块，向量检索 | 与关键词组事实结论一致 | 回答包括七轮重试、自动校时和17天保留期限 |
| 当前期限问题 | 新旧版本均进入未过滤向量Top-2 | 模型本轮仍按有效版本回答17天；过滤是结构保障，本轮未体现准确率提升 |
| 60字分块，向量检索 | 断网题Top-2为sync:0和retention-v1:0 | 命中正确文档，却缺少具体重试轮数；相关性分数不是正确概率 |
| 学生优惠 | 检索仍返回相似片段，但生成拒答 | 总有Top-2不等于知识库有答案 |

三道可回答问题，所有检索配置的文档级Hit@1、Hit@2和MRR均为1；但60字向量组的关键证据短语覆盖仅2/3，120字为3/3。这说明文档命中指标会掩盖细节缺失。关键短语覆盖是精确字符串检查，不能代替完整语义评估。

无答案题没有正相关文档，不纳入Hit与MRR分母，单独检查是否拒答。

四组生成结果均通过JSON格式与引用ID存在性检查。人工阅读已核对主要事实与提供证据一致；引用ID存在不代表引用必然支持答案，未使用独立LLM裁判。

## 补充：小分块导致回答缺失

补跑60字向量Top-2后的真实回答：能够说明本地排队、联网后上传，但明确表示重试轮数资料不足，没有编造“七轮”。它还笼统称恢复后的具体处理资料不足，存在措辞过度拒答的问题，因为前文证据已经说明自动上传。

因此，失败链条是：正确文档被命中 → 必要细节位于未召回片段 → 模型无法完整回答。可尝试按完整句段切分、同源相邻块扩展、增加Top-k或混合检索；本轮只验证增大分块到120字的效果，其他方法尚未运行。

## 与用户记忆的联系

用户记忆回答“这个用户有什么偏好、当前哪个事实有效”；知识库提供回答问题所需的外部依据。前一个实验从JSON文件读取当前做饭偏好，本实验检索产品规则，二者可在同一请求中组合。教学偏好不能修改产品事实，也不应被当成产品规则检索。

补充实验实际从上一实验memory.json读到active的做饭偏好，将其与120字过滤后检索证据同时放入请求。真实输出包含七轮重试和本地队列等事实，但未使用做饭比喻，且未按要求给出chunk_id。它还把“不会立即丢弃”表述为“不会丢”，措辞比证据更强。因此该次组合实验只能确认记忆读取与RAG链路接通，不能判为偏好遵从和引用通过。应分别评分事实依据、偏好遵从、引用质量，后续可加强输出结构并再次验证；本报告不宣称这些问题已修复。

两项补充实验的请求、回答与读回记忆保存在rag-followup-20261015-01；小分块实验与组合实验同时改变了分块大小和偏好，不能通过它们的差异单独估计记忆的因果效应。
