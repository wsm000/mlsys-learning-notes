# 3-8：检索不够时，谁决定下一步查什么？

## 本实验要实现的机制

像查蜂场档案：先看到青禾蜂场管理蜂群A，下一步应追查蜂群A；发现蜂螨后，再查关联手册。Agentic RAG把“是否继续搜、下一次搜什么”的决定放进模型与工具的反馈循环。

本轮真实运行两条路径：

```text
固定RAG：问题 → 检索一次 → 证据 → 回答

Agentic RAG：问题 → 首次检索 → 证据
                               ↓
                        模型输出search或finish
                         /                \
                新查询→检索→新证据          回答
                         └────回到模型─────┘
```

程序负责真正执行search、合并证据、限制次数和拦截重复查询。模型只选择动作与查询，不凭自己说“我已经搜索过”来替代工具执行。

## 公平对照保留了什么？

vm-60，同一8条蜂场档案、同一本地Qwen3-0.6B、同一BM25实现、每次取Top-2；两条路径的第一次检索完全相同；最后回答使用相同提示与输出上限。Agent路径最多追加3次搜索，累积新证据。

替代官方法律问答语料，以3个小问题展示机制；显式词表分词；没有外部质量评委。因此是等价教学实验，不是官方原样基准。只请求短动作JSON，没有要求模型暴露内部思维过程。

## 一道多跳题的完整中间结果

问题：**青禾蜂场管理的蜂群遇到了什么问题，应参考哪本手册，第一步要做什么？**

### 1. 第一次检索，两条路径收到相同证据

```text
[C1] 青禾蜂场位于河谷镇。青禾蜂场管理蜂群A。
[C4] 河谷镇冬季寒冷。青禾蜂场冬季管理包括保温和饲料检查。
```

这两段只解决了“管理哪群蜂”，没有提供蜂螨问题和手册要求。固定RAG的回答说明证据未提供具体问题，没有给出正确的完整答案。

### 2. Agent控制器真实输出

```json
{"action":"search","query":"青禾蜂场冬季管理"}
```

程序执行该查询，仍只取到C1、C4，没有新证据。随后模型再次输出相同查询，被重复查询保护拦截。

这一步清楚地区分了：

- **动作格式成功：**模型输出有效JSON，程序实际执行搜索。
- **检索计划失败：**它跟随了无关的冬季信息，没有追踪问题所需的蜂群A。
- **停止控制失败：**模型重复搜索，最后是程序拦停，不是模型自行判断证据已足够。

最终答案仍说明证据缺失，所需C1、C2、C3中只进入C1，来源覆盖1/3，和一次检索相同。这里的覆盖是来源到达情况，不是答案质量评分。

### 3. 怎样知道应改哪里？

C2就在资料中，写着“蜂群A发现蜂螨。蜂螨防治参考手册M”；C3写着手册M先监测蜂螨数量。问题不是原文不存在，也不是这两段被切断，而是控制器没有发出能找到它们的后续查询。

从原文可以诊断，追踪“蜂群A”再追踪“手册M”是合理路线。但这不是本轮模型执行的轨迹，不能把这条人工诊断路径冒充Agent成功结果。

## 三个问题分别发生了什么？

| 问题 | 第一次证据 | 模型追加查询 | 实际收益 |
|---|---|---|---|
| 手册M要求先做什么 | C3、C2，已经足够 | 蜂螨防治 | 无新增来源，搜索多余 |
| 青禾蜂场的蜂群问题与手册要求 | C1、C4，不够 | 青禾蜂场冬季管理 | 方向偏离，仍缺C2、C3 |
| 蜂螨数量达到多少必须处理 | C3、C2，没有数值阈值 | 蜂螨数量达到多少 | 未找到阈值，两条路径均说明证据未给出 |

三题都在第二次控制器输出时重复了上一次追加查询，由程序拒绝重复并停止，实际各执行2次检索。没有用脚本替模型填写正确的下一条查询。

多跳题本轮一次检索路径的回答耗时约2.64秒，Agent控制与回答约3.96秒；统计不含模型加载和共享的首次检索。单轮小样本耗时只作观察，不能推广成服务性能结论。

## 为什么有这个机制，却没有获得提升？

Agentic RAG带来的是“根据已见证据改变检索行动”的能力入口，并不自动提供可靠的规划能力。本例已展示真实模型—工具循环，但控制器没有找对信息缺口，因此更多调用没有带来更多有效证据。

这正好划清三个层次：

1. **机制存在：**模型能发动作，工具能执行，结果能反馈。
2. **策略有效：**新动作是否补上当前缺失的证据。
3. **最终回答可靠：**证据充分后是否准确回答、引用支持结论。

本轮第1层跑通，第2层暴露失败；最后回答也有照抄问题、引用不完整等问题，不能仅凭没有编造数值就判定整体优秀。没有得到“Agent一定优于固定RAG”的结论。

## 与前一项的区别

3-7预先把知识组织成树或图；本轮的8条原文没有建图，3-8让模型在回答时临时决定搜索路线。前者改变知识组织，后者改变检索控制。二者可以组合，但不是同一机制。
