# 3-10：给孤立文本块补上“它在说谁、何时、哪件事”

## 本实验想实现什么机制？

像捡到一张巡蜂资料卡，上面只写“本季产量增长30%”。它缺少蜂场、年份和季节，单独检索时容易与其他记录混淆。

上下文感知检索在建索引时，让模型同时读“完整来源文档”和“目标块”，生成短背景，再把背景与原文一起建立索引：

```text
完整文档＋目标块 → 模型生成背景前缀
                           ↓
                     前缀＋原始块
                           ↓
                     BM25／向量索引

问题 → 原来的检索流程 → 有来源背景的候选块
```

前缀在建索引阶段生成，本轮没有把测试问题或正确答案给前缀模型。它不是回答时临时追加聊天历史，也没有重新训练模型。

## 实际输入与对照

vm-60：4份自建蜂场报告、12个块、6个固定标注问题。报告分别为青禾2025春、白石2025春、青禾2025秋、青禾2024春。测试问题明确指定蜂场、年份、季节。

- 普通分支：只索引块正文。
- 上下文分支：索引模型生成的前缀＋完全不变的正文。
- 两分支使用相同分词、BM25、真实BGE向量、RRF融合与问题。
- 前缀由本地Qwen3-0.6B逐块实际生成，不是人工填写。
- 标题元数据两边都保留，但主对照的普通分支没有把标题用于排序或过滤；另做元数据对照。

属于等价机制实验，不是官方原样规模验收。

## 一、原始块为什么会混淆？

来自两个不同年份的A1和D1，正文完全相同：

```text
本季蜂蜜产量增长30%，主要来自油菜蜜。
```

A1实际属于“青禾蜂场2025年春季”，D1属于“青禾蜂场2024年春季”。只有正文时，即使向量搜索完全精确，也无法从这两段相同文字中知道年份。普通分支的并列候选按文档ID排序，排对某一题也可能只是恰好打破平局。

这不是ANN没找到近邻，而是索引表示缺少来源信息。

## 二、模型生成了什么？

实际生成结果：

```text
A1前缀：青禾蜂场｜2025年春季生产报告
D1前缀：青禾蜂场｜2024年春季生产报告
```

新索引输入为：

```text
青禾蜂场｜2024年春季生产报告
本季蜂蜜产量增长30%，主要来自油菜蜜。
```

12个前缀本轮都恰好等于各自来源标题，没有生成更细的块主题。没有替模型加写理想前缀。它们保留了主体和时间，但本例并未体现模型从复杂长文中推断隐藏背景的能力。

## 三、同一个问题，排名怎样变化？

问题：“青禾蜂场2024年春季增加了多少箱蜂？”正确块是D2：10箱。A2是2025春的20箱，C2是2025秋的3箱。

| 索引与方法 | 前三名 |
|---|---|
| 普通BM25 | C2、A2、D2 |
| 普通向量 | C2、A2、D2 |
| 补前缀BM25 | **D2**、A2、C2 |
| 补前缀向量 | A2、**D2**、C2 |

补背景后，BM25可以利用准确的年份与季节词；向量检索仍把相近的2025春排在2024春前。**把年份写进文本，只增加了排序信号，并没有建立“年份必须相同”的硬约束。**

## 四、六题的实际结果

| 方法 | 正确块排第一 | 正确块进前三 |
|---|---:|---:|
| 普通BM25 | 2/6 | 6/6 |
| 补前缀BM25 | 6/6 | 6/6 |
| 普通向量 | 2/6 | 6/6 |
| 补前缀向量 | 4/6 | 6/6 |
| 普通RRF混合 | 2/6 | 6/6 |
| 补前缀RRF混合 | 4/6 | 6/6 |

本轮改善的是**排序位置**，不是Recall@3；普通分支已经将正确块放进前三。没有运行最终生成答案，不能据此称问答正确率提高到了100%。设计语料很小，也不能把这个比例推广到其他知识库。

## 五、能直接用元数据，为什么还要调用模型？

本例不必调用模型。标题本来就包含所需信息，直接继承标题便能得到与本轮模型前缀完全相同的索引输入。已逐条核对12个生成前缀均等于来源标题。

另外，用保存的普通向量分数做确定性回放：先按问题明确指定的蜂场、年份、季节筛掉不匹配文档，再按原向量分数排序，6题全部把正确块排第一。这个对照没有额外调用编码器或生成模型，也不是模型自主理解复杂时间意图。

因此要区分：

- **结构化信息已有：**继承标题、元数据过滤通常更直接。
- **背景分散在正文：**可以让模型生成来源背景，但要核对是否忠实。
- **条件必须满足：**用明确过滤表达，不只依赖语义相似度。

## 成本与风险

12次前缀生成，本轮累计输入1744 tokens、输出168 tokens，生成总耗时约5.70秒，不含模型加载。运行在本地，没有计算API账单价格；本地计算也不能当作零成本。

前缀若写错主体、年份或从其他段落偷带不适用结论，错误会进入索引并影响后续查询。本轮数字引入检查没有触发警告，但这种检查不能证明所有前缀都语义正确。原文、来源与模型原始输出仍应保留。
